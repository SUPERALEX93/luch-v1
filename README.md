# ЛУЧ v1

Первая версия голосового ассистента для Linux: слушает микрофон, проверяет, что
говорит владелец, распознаёт речь, спрашивает локальную модель и отвечает голосом.

## Что умеет

| Возможность | Реализация |
|---|---|
| Распознавание речи | faster-whisper (локально) или Google через `speech_recognition` |
| Синтез речи | Silero TTS, русские голоса |
| Голосовой пропуск | speechbrain (ECAPA): ассистент реагирует только на ваш тембр |
| Диалог | локальная модель через Ollama |
| Слово-триггер | обращение по заданному слову (по умолчанию «луч») |
| Управление ПК | `terminal`, `lock_pc`, `print_text`, `web_search` |
| Веб-интерфейс | простой FastAPI-сервер |

Ассистент работает в двух режимах: слушает микрофон и ждёт триггер-слово, либо
принимает текст в консоли.

## Установка

Нужен Python 3.11+ и запущенный [Ollama](https://ollama.com).

```bash
python -m venv venv && source venv/bin/activate

# torch и torchaudio для CUDA ставятся из отдельного индекса
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu130

pip install faster-whisper SpeechRecognition speechbrain silero-tts \
            ollama fastapi uvicorn pygame-ce numpy scipy \
            python_speech_features requests colorama art
```

## Запуск

```bash
python main.py
```

При первом запуске ассистент попросит произнести длинную фразу — это эталон
вашего голоса, он сохранится в `my_voice_profile.wav`. Файл нужен для голосового
пропуска, поэтому в репозиторий он не попадает.

Веб-интерфейс: `http://<ip>:1337`

## Настройки

`settings.json` создаётся автоматически:

| Ключ | Назначение |
|---|---|
| `model` | модель Ollama |
| `whispermodel` | модель распознавания речи |
| `stt_mode` | `whisper` или `google` |
| `micro_index` | индекс микрофона |
| `tts_voice` | голос синтеза речи |
| `trigger_word` | слово обращения к ассистенту |
| `speed_ai_speak` | скорость речи |

## Важно про безопасность

**В этой версии у веб-API нет никакой аутентификации** — кто угодно в вашей сети
может отправить запрос и выполнить команду на компьютере. Сервер слушает `0.0.0.0`
и отдаёт эндпоинты без токена.

Не выставляйте порт 1337 в интернет. В версии 1.8 добавлена обязательная
аутентификация по токену.

## Чем отличается от следующих версий

Здесь ещё нет: красивого консольного меню (`rich`), облачных провайдеров кроме
Ollama, отдельного веб-интерфейса (`static/`), GUI-пульта, навигации и
Android-приложения. Всё это появилось в v1.5–v1.7.
